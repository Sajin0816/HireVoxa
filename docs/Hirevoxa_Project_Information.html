1. Executive Overview & Market Problem

United States technology organizations face persistent headwinds when scaling software engineering teams: domestic engineering talent commands soaring compensation benchmarks, while traditional offshore outsourcing (e.g. Eastern Europe, South Asia) introduces crippling 10-to-12 hour timezone delays, severe communication friction, and erratic technical vetting. Furthermore, legacy recruitment agencies impose exorbitant, non-refundable placement retainers typically amounting to 20% to 30% of first-year salaries.

The LatAm Nearshore Advantage

  • Direct Timezone Synchronicity: Latin American engineering hubs in Brazil, Argentina, Colombia, and Mexico operate in EST, CST, and PST windows (0 to 3 hours offset). No midnight standups or overnight blockages.
  • Exceptional Technical Depth: Top-tier university systems, strong open-source contribution cultures, and fluency in modern stacks (React, TypeScript, Node.js, Python, Go, Cloud).
  • English Fluency: Standardized B2-C2 professional English verification ensures direct participation in product architecture and executive discussions.

The Hirevoxa Solution

  • Deterministic Multi-Vector Matching: Mathematical compatibility scoring comparing technical competencies, seniority, and operational overlap.
  • Full Recruitment ATS: End-to-end requisition posting, candidate review, 1-click video interview scheduling, and offer tracking.
  • Transparent Economics: Free candidate tier, Starter pilot ($0), Pro subscription ($199/mo), and a flat $2,500 success placement fee backed by a 90-day replacement policy.

3. Security Architecture, Authentication & RBAC

Hirevoxa enforces a zero-trust security perimeter across candidate, employer, and administrative contexts. Identity verification utilizes dual-token authentication combining HttpOnly SameSite cookies with standard Bearer headers for complete client compatibility.

Dual-Layer JWT Authentication

When a user signs in, the backend signs a JSON Web Token with HMAC SHA-256 and delivers it via two concurrent channels:

  • HttpOnly Cookie: Secure, SameSite-strict cookie inaccessible to JavaScript, protecting against Cross-Site Scripting (XSS) session theft.
  • Bearer Token: Returned in response payload for API client authorization and local context tracking.
  • Token Claims: Contains userId, role, email, companyId, and status.
  • Password Security: Hashed using bcryptjs with 10 salt rounds. Plaintext passwords never hit the database or logs.

Role-Based Access Control (RBAC)

The system establishes 3 distinct user personas with mutually exclusive route boundaries:

Company /app/* Requisition management, talent discovery, candidate scheduling, ATS.
Candidate /candidate/* Profile builder, resume upload, job applications, interview view.
Admin /admin/* Company vetting, job moderation, user suspension, fee audits.

*Admin sub-roles (owner, ops_admin, analyst) enforce granular operational segregation.

4. Professional Global Form Validation Framework

To deliver a seamless, high-trust enterprise user experience, Hirevoxa has eliminated generic native browser tooltips (e.g. "Please fill in this field.") across 100% of its forms in favor of an accessible, unified React validation system.

1. Complete Native Tooltip Suppression

Every <form> element specifies noValidate. Native HTML5 required attributes are disallowed to prevent disruptive browser popups.

2. Centralized Validation Utilities

3. Accessible FieldError Component

FieldError.jsx renders smooth, subtle red alert messages below inputs with AlertCircle icons, role="alert", and aria-live="polite".

6. Hiring Organization Workspace (/app) & ATS Workflow

The employer portal is designed for high-velocity US recruiting teams, providing complete requisition management, algorithmic talent discovery, and an integrated Applicant Tracking System (ATS).

Job Requisition Management (/app/jobs)

  • Create, publish, pause, and close engineering job posts with title, department, and description.
  • Set required tech stacks, minimum years of experience, and hourly/monthly budget ranges.
  • Enforce timezone synchronicity requirements (EST, CST, PST, BRT).
  • Server-side entitlement validation gates active jobs (5 for Starter, 50 for Pro).

Applicant Tracking Pipeline (/app/applications)

  • Structured candidate cards displaying match scores, profile highlights, and resumes.
  • Stage progression: Submitted → Under Review → Shortlisted → Interview Scheduled → Offered → Hired.
  • Internal notes feature for recruiter evaluation (masked from candidates).
  • Single-click interview modal with timezone alignment and calendar integration.

Deterministic Matching Engine

Rather than opaque AI approximations, Hirevoxa calculates candidate compatibility mathematically via weighted multi-vector scoring:

  • Skills Compatibility (50%): Jaccard set intersection between job requirements and candidate tech stack.
  • Seniority & Experience (25%): Candidate verifiable experience vs. role requirements.
  • Timezone Alignment (25%): Synchronous operational working hours overlap.

Interview Coordination (/app/interviews, /calendar)

  • Interactive weekly calendar with multi-timezone toggling (EST, BRT, PST).
  • Week navigation offsets (<, This Week, >) with 0 stuck-loader guarantees.
  • Video conferencing link generation and standardized candidate notification.
  • Status tracking: Pending → Confirmed → Completed → Cancelled.

9. Deterministic Matching Engine Mathematics

The core matching engine (server/src/services/matchingService.js) computes an objective compatibility score (0.0 to 10.0) between candidates and open job requisitions based on three normalized algorithmic vectors:

Mathematical Score Formulation:

Compatibility Score = (Skills Score * 0.50) + (Seniority Score * 0.25) + (Timezone Score * 0.25) Where: • Skills Score = |CandidateSkills ∩ JobRequiredSkills| / |JobRequiredSkills| (with partial sub-match) • Seniority Score = min(1.0, CandidateYearsOfExperience / JobMinimumYearsRequired) • Timezone Score = Synchronous Working Hours Overlap / 8.0 (Overlap between EST/CST/PST and LatAm)

11. Database Schema & Data Models

The persistence layer is governed by Mongoose 8.10+ schemas on MongoDB Atlas (replica set) with compound indexes designed for high-throughput queries and strict data isolation.

Core Schemas & Indexing

User email (unique), password (bcrypt), role, adminRole, status, companyId.
Company name, tenantKey (unique sparse), ownerId, plan, verificationStatus.
Candidate userId (unique sparse), title, country, timeZone, skills, yearsOfExperience.
Job companyId, title, department, requiredSkills, budgetRange, status.
Application candidateUserId, jobId, companyId, status, statusHistory.
Interview companyId, candidateId, jobId, proposedDate, timeZone, meetingLink.
AuditLog actor, action, targetResource, outcome, clientIp, timestamp.

Connection Resilience & Security

  • Transient Auto-Retry: connectDB() retries up to 3 times with exponential backoff on network/TLS hiccups.
  • Credential Masking: Automatic regex scrubbing replaces mongodb+srv://user:pass@host with user:***@host before logging.
  • Unique Constraint Safeguard: Compound index { candidateUserId: 1, jobId: 1 } prevents duplicate applications at the database engine level.
  • Tenant Isolation: Company queries explicitly filter by companyId to guarantee strict cross-tenant data privacy.
  • Live Restart Persistence: Fully verified in MongoDB Atlas cluster across Express server restarts.

Local Development Quick Start

Prerequisites: Node.js 22 LTS, npm 10+, MongoDB Atlas account or local MongoDB 7+.

# 1. Clone repository
git clone https://github.com/Sajin0816/HireVoxa.git
cd HireVoxa

# 2. Install dependencies
npm --prefix server install
npm --prefix client install

# 3. Configure environment (.env)
PORT=5000
MONGODB_URI=mongodb+srv://...
JWT_SECRET=your_super_secret_key_at_least_32_chars
NODE_ENV=development

# 4. Seed database
npm --prefix server run seed

# 5. Start dev servers
npm --prefix server run dev # Port 5000
npm --prefix client run dev # Port 5173
